# turnos-appointments-service

Servicio de turnos y reservas del sistema distribuido de turnos. Gestiona los usuarios
de la aplicación, calcula la disponibilidad y coordina con el servicio central de la
cátedra el flujo de reserva.

Forma parte del sistema junto con
[turnos-catalog-service](https://github.com/Final-Programacion-II/turnos-catalog-service)
y [turnos-kmp-app](https://github.com/Final-Programacion-II/turnos-kmp-app).

Documentación en [`docs/`](docs/).
